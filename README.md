# BOM Tools - Excel Add-in

Adds a **BOM Tools** button on Excel's Home tab with four clean tabs:
1. **Home** — opens here by default with workbook status and quick-action cards for every common task, plus a collapsed *Troubleshooting & Repair* drawer at the bottom.
2. **Add Sheet** — uncluttered form (just Sheet name + Add BOM Sheet) with project name, copy source, clear data, and local sync tucked inside a *More options* dropdown, and *Troubleshooting & Repair* at the bottom.
3. **Materials** — unobstructed Master list (with clean BOM-ready status icons for Name, Primary Unit, and Weight) and streamlined Add/Edit/Remove editor with calm primary-requirement guards, aesthetic auto-collapsing change notifications with a compact **Session changes** log, and zero-setup **Built-in Add-in Storage + JSON Backup & Transfer** tucked neatly at the bottom.
4. **Convert** — two-way converter: **Flatten for Sharing** (Auto-growing, Fixed, and Compiled Purchase List) and **Restore Automated** (converts flattened BOM sheets right back into full automated BOM sheets with `Master Unique Materials`, hidden `BOM Blank`, dropdowns, formulas, and preserved Stock/PO values).

## 1. Host the files
Host this folder on any HTTPS static host (GitHub Pages or Netlify Drop), then replace `https://YOUR-HOST` in `manifest.xml` with your base URL (no trailing slash):

    sed -i 's#https://YOUR-HOST#https://<you>.github.io/<repo>#g' manifest.xml

## 2. Install the manifest
- **Excel on the web**: Insert > Add-ins > Manage My Add-ins > Upload My Add-in > pick `manifest.xml`.
- **Excel for Windows**: place `manifest.xml` in a shared folder registered under File > Options > Trust Center > Trust Center Settings > Trusted Add-in Catalogs (tick *Show in Menu*), restart Excel, then Insert > My Add-ins > Shared Folder > BOM Tools.
- **Microsoft 365 organization-wide**: Admin center > Settings > Integrated apps > Upload custom apps.

## 3. Built-in Computer Storage + JSON Backup & Transfer (Zero Setup, Never Reconnects)
1. **Works automatically out of the box** — every material addition, edit, or removal (from either the task pane or directly on the `Master Unique Materials` worksheet) saves silently inside Excel's built-in add-in storage (OPFS + IndexedDB + local storage) and **never asks to reconnect** after restarting Excel.
2. Whenever you create a **new BOM sheet**, add a BOM to a **non-BOM workbook**, or **restore a converted BOM**, your latest saved materials list loads automatically.
3. **Backup or move to another computer**: open **Materials > Backup & Transfer (JSON)** and click **Export JSON backup** to save `master-materials.json`, or **Import JSON...** on another computer to load it immediately.

- **Add-in Version Badge & Selectable Saved Project-Only Material Lists (v2.2)**:
  - **Visible version tag**: the sticky header now displays `v2.2` (or `v2.2 · Offline` in the Offline Windows LTS edition) next to **BOM Tools** on every tab so you can immediately verify which version Excel loaded.
  - **Browse, select, restore, export, or delete any saved Project-Only list right inside the add-in**: scans all built-in storage layers (`localStorage`, IndexedDB, OPFS, and `C:\ProgramData\BOMTools\data\projects\` in Offline LTS) so even project lists created before flattening or before v2.2 appear automatically.
  - **Convert > Restore Automated** now offers a clear 3-way **Materials list to restore with** picker (**Global Master list**, **Saved Project-Only list on this PC** dropdown, or **Project Materials `.json` file**), and **Materials** includes a **Saved Project Lists on this PC** drawer to load, export, or delete any saved project list anytime.
  - Hardened `BomProjectList` custom property writes (`custom.add`) and re-stamps it before full flattening so project links survive reliably.
- **Fixed Auto-Growing Excel 365 Purchase List & Selective Sheet Flattening (v2.1)**:
  - **Fixed empty Auto-growing purchase list**: replaced the non-existent Office.js `range.formulas2` call with `range.formulas` (which natively writes Excel 365 `SORT(UNIQUE(FILTER(...)))` and `$AB$5#` dynamic arrays without dropping formulas), and upgraded **Upgrade / Repair Purchase-List Names** so it can also rebuild any sheet left empty by v2.0.
  - **Selective Sheet Flattening (keeps Master sheet on partial flatten)**: **Convert > Flatten for Sharing** now displays a per-sheet selection checklist (`All` / `None`). Whenever at least one automated BOM sheet is left unselected, `Master Unique Materials`, hidden `BOM Blank`, and all 7 workbook named ranges are automatically kept intact so remaining automated pages continue working normally.
- **Excel 365 Dynamic Array Auto-Growing Purchase List & Best-of-Both Project-Only Lists (v2.0)**:
  - **Excel 365 `SORT(UNIQUE(FILTER(...)))` Auto-Growing Purchase List**: hidden `AB5` holds `=IFERROR(SORT(UNIQUE(FILTER($C$5:$C$<tot>,($C$5:$C$<tot><>"")*($C$5:$C$<tot><>"Materials")))),"")`, `AE2` holds `=IF($AB$5="",0,ROWS($AB$5#))`, and `P5:P47` uses `INDEX($AB$5#,(ROW()-4))` — all written via `range.formulas2` (ExcelApi 1.9+) so Excel 365 never injects `@`. Any custom/unlisted material added after flattening appears alphabetically right away. Use **Fixed purchase list (No automation)** when sharing with non-365 Excel.
  - **Upgrade / Repair Purchase-List Names**: new collapsible tool in **Convert > Restore Automated** upgrades already-converted Auto-growing sheets in place to the Excel 365 dynamic list without touching BOM rows or Stock/PO inputs.
  - **Best-of-Both Project-Only Material Lists**: stores the Project-Only flag in Workbook Custom Property (`BomProjectList`) so it survives Flattening and **Restore Automated** detects it automatically; gives each project its own isolated built-in storage slot on this PC (and under `C:\ProgramData\BOMTools\data\projects\` in Offline LTS); adds a searchable checkbox **Pick specific materials from Global Master** start mode alongside Copy all, Used-only, and Blank; auto-checks **Save project materials (.json) automatically before converting** on Flatten; lets you preload a project `.json` even on converted workbooks; and blocks importing a project `.json` into Global Master Backup.
- **Auto-Growing Custom Materials Fix & Isolated Project-Only Material List (v1.9)**:
  - **Custom materials in Auto-growing Plain Excel**: eliminated hidden helper columns `M` and `AB` from `plFormulas()`. Column `P` now extracts unique material names directly from `$C$5:$C$<tot>` using classic non-CSE `INDEX/MATCH/COUNTIF` formulas, so typing or inserting ANY custom/unlisted material after flattening immediately displays its name in the Purchase List. Qty (`R`) now safely handles blank `Set` cells via `SUMPRODUCT + SUMIFS`, capacity increased from 25 to 40 materials, and Fixed mode also preserves unlisted custom materials.
  - **One-Time / Project-Only Material List**: create an isolated per-workbook material sheet (starting from a copy of Global Master, only materials currently used in the workbook, blank, or loaded from a `.json` file). All edits/adds/deletions stay strictly inside that workbook without modifying your Global Master list, can be saved as a separate reusable `<project>-materials.json` file (with a reminder right before Flattening), and can be reloaded directly during **Convert > Restore Automated**.
- **Built-in Add-in Storage (Zero Reconnects), JSON Backup/Transfer & Calm Requirement Guards (v1.8)**: replaced external hard-drive file linking (which forced a reconnect prompt every Excel restart) with always-on **Built-in Add-in Storage** (OPFS + IndexedDB + `localStorage` + persistent storage request) paired with 1-click **Export JSON backup** / **Import JSON...** for backups or transferring between computers; added live primary-requirement guards across Materials, Add Sheet, Convert (Flatten & Restore), and Repair so actions cannot run until required inputs are valid (e.g. Material name, Primary unit, positive Weight/Sheet Size, valid non-duplicate Sheet name, copy confirmation, or at least one sheet selected), shown with a calm, non-annoying inline hint that disappears as soon as requirements are fulfilled.

- **Materials "More options" & Top Auto-Saved Feed (v1.6)**: optional fields (**Category**, **Remarks**) are tucked inside a collapsible **More options** dropdown so adding a material only asks for Name, Unit, and Weight, and changed materials bubble to the top of the list.

- **Home-first UI & streamlined panels (v1.3)**: opens to a **Home** tab with quick options; optional Add Sheet fields, Repair tools, and plain-English Local Master Save are neatly tucked into collapsible dropdowns so everyday editing stays fast and uncluttered.
- **Restore Automated BOM (v1.3)**: converts flattened/plain BOM sheets back into full automated BOM sheets with `Master Unique Materials`, hidden `BOM Blank`, `bom_*`/`pl_*` tables, live dropdowns, formulas, and preserved Stock/PO values.
- **Local computer master file sync (v1.2)**: uses the File System Access API + IndexedDB handle persistence + local computer storage cache so materials sync automatically across workbooks without a GitHub token; supports adding, editing, and removing materials (`deleteMaterial` + removal sync).
